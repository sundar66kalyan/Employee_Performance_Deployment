# 📌 Overview

The Employee Performance Prediction System is an AI-powered Human Resource Analytics application that predicts employee performance ratings using Machine Learning.

The application helps HR professionals make data-driven decisions related to:

- Employee Performance Evaluation
- Promotion Planning
- Leadership Identification
- Employee Retention
- Performance Improvement Planning

The project was developed as part of the **IABAC Certified Data Scientist Capstone Project**.

---

# 🎯 Business Problem

Organizations evaluate employee performance using multiple factors including:

- Experience
- Job Satisfaction
- Salary Hike
- Environment Satisfaction
- Work-Life Balance
- Department
- Job Role

Traditional evaluation methods are subjective and time consuming.

This project applies Machine Learning to automate and improve performance prediction.

# ▶️ Installation

Clone repository

```bash
git clone https://github.com/sundar66kalyan/Employee_Performance_Deployment.git
```

Move into project

```bash
cd Employee_Performance_Deployment
```

Install requirements

```bash
pip install -r requirements.txt
```

Run application

```bash
streamlit run app.py
```
